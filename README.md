
# Iris Flower Classification using Machine Learning

## Project Overview
This project classifies Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## Technologies Used
- Python
- Scikit-learn
- NumPy
- Matplotlib

## Machine Learning Model
Random Forest Classifier

## Dataset
Built-in Iris dataset from Scikit-learn.

## Model Accuracy
90%

## Project Output
The model predicts flower species using flower measurements and displays a classification report and dataset graph.

## How to Run
1. Install required libraries.
2. Run iris_classification.py.
